## About

GlzzLexi Studios is an independent game studio founded and led by **Gabriel Ronao**. The studio develops Roblox experiences on a shared foundation of reusable Luau modules covering data persistence, gameplay systems, and development tooling. Expanding into standalone 3D first-person desktop games distributed directly on our official studio website at **[glzzlexi.me](https://glzzlexi.me/)**.

The studio is currently solo-operated. Its stated objective is to grow into a small, specialized team of developers, technical artists, and scripters.

### Target Genres & Architecture Focus

Beyond our immediate pipeline, our modular framework is designed to support titles across these core verticals:

| Genre | Description | Status |
| :--- | :--- | :--- |
| **Systems-driven** | RPGs, economy loops, governance simulations, and progression | **Primary Focus / Active Production** |
| **Survival** | Resource gathering, crafting, and dynamic environments | Delayed / On Hold |
| **Action** | First-person shooters and tactical combat | Planned |
| **Platforming** | Obstacle courses, speed-runs, and physics-driven movement | Planned |

### Development Approach

We favor small, focused releases over a single large launch. This approach shortens delivery cycles, surfaces player feedback early, and allows each release to strengthen the shared codebase used by later titles. Projects that validate their core loop receive long-term support, while underperforming prototypes are cleanly archived so resources remain focused on high-potential titles.

## Join the Team

**Current Status:** `Selective Roster / Pipeline Network`

GlzzLexi Studios operates as a lean, self-sufficient studio. While active recruitment is closed and core production is handled in-house, we maintain a private developer registry for high-impact collaborators as upcoming releases scale.

- **Partnership & Revenue Model:** Collaboration is handled strictly through mutually agreed **Project Revenue Sharing (Rev-Share)**. Split percentages, delivery milestones, and payout structures are defined and agreed upon between both parties prior to project kickoff, ensuring total alignment, transparent accounting, and full compliance with Roblox Terms of Service via native Roblox Group payouts.

If you are a disciplined developer, technical artist, or 3D generalist interested in collaborating on future releases, submit your profile to **[glzzjhn@gmail.com](mailto:glzzjhn@gmail.com)** with the subject line `Application: [Your Role]`:

- **Focus & Expertise:** Core disciplines (e.g., Modular Luau, Technical Art, UI/UX, Environment Design)
- **Proof of Work:** Verified portfolio, GitHub profile, or active Roblox Creator Hub showcases
- **Commitment:** Weekly availability and milestone turnaround capacity
